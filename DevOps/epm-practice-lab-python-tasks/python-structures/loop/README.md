# Երբեմն օգտակար է ունենալ pytest թեստեր — օրինակ test_loop.py

Սա մի շատ պարզ pytest- ֆայլ, որը թեստավորում է նվազագույն դեպքերը, այդ թվում 0, փոքր թվեր, և մի բացասական թիվ, որը պետք է բարձրացնի սխալ։
Այն պետք է տեղադրես նույն թղթապանակում որպես test_loop.py։
    դրանից հետո աշխատեցրու pytest-ը (վայրում .venv ակտիվ է)՝ pytest -q կամ պարզապես pytest։

##Ինչպես գործարկել ձեռքով (օրինակներ)

    Տերթել ֆայլը օրինակով: 
    $ echo 3 | python3 loop.py
    6
    Կամ
    $ python3 loop.py
    3
        (մուտքագրիր 3՝ ENTER)
        կարող ես ստանալ 6
